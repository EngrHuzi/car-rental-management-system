\section{Overview}

\textbf{RentalPro} is a comprehensive, enterprise-grade car rental management system designed to streamline fleet operations, enhance customer experience, and provide actionable business insights through AI-powered analytics.

\subsection{What Makes RentalPro Special?}

\begin{itemize}[leftmargin=*]
    \item \textbf{Modern UI/UX}: Vibrant gradient-based design system with smooth animations
    \item \textbf{AI Integration}: Intelligent chatbot and automated business insights
    \item \textbf{Real-time Analytics}: Live dashboards with interactive charts and KPIs
    \item \textbf{Enterprise Security}: JWT authentication with email verification
    \item \textbf{Fully Responsive}: Optimized for desktop, tablet, and mobile devices
    \item \textbf{High Performance}: Built with Next.js 16 for optimal speed and SEO
    \item \textbf{Type-Safe}: Full TypeScript support for reduced bugs
    \item \textbf{Real-time Updates}: Instant data synchronization across all modules
\end{itemize}

\section{Installation}

\subsection{Prerequisites}

Before installing RentalPro, ensure your system meets these requirements:

\begin{enumerate}
    \item \textbf{Node.js} (v18.0.0 or higher)
    \item \textbf{MySQL} (v8.0 or higher)
    \item \textbf{Git} (Latest version)
\end{enumerate}

\subsection{Installation Steps}

\subsubsection{Step 1: Clone the Repository}

\begin{lstlisting}[language=bash]
# Using HTTPS
git clone https://github.com/yourusername/car-rental-management-sys.git

# Navigate to project directory
cd car-rental-management-sys/my-app
\end{lstlisting}

\subsubsection{Step 2: Install Dependencies}

\begin{lstlisting}[language=bash]
# Using npm (recommended)
npm install
\end{lstlisting}

This installs:
\begin{itemize}
    \item Next.js and React core libraries
    \item Prisma ORM and client
    \item Authentication packages (JWT, bcrypt)
    \item UI components (Tailwind, Framer Motion, shadcn/ui)
    \item Validation libraries (Zod)
    \item Email service (Nodemailer)
\end{itemize}

\subsubsection{Step 3: Environment Configuration}

Create a \texttt{.env} file in the root directory:

\begin{lstlisting}[language=bash]
# Database Configuration
DATABASE_URL="mysql://root:yourpassword@localhost:3306/car_rental_db"

# JWT Authentication
JWT_SECRET="your-super-secret-jwt-key-min-32-chars"
JWT_EXPIRES_IN="7d"

# Email Configuration (Gmail)
EMAIL_USER="your-email@gmail.com"
EMAIL_PASSWORD="your-app-specific-password"
SMTP_HOST="smtp.gmail.com"
SMTP_PORT="587"

# Application Settings
NEXT_PUBLIC_APP_URL="http://localhost:3000"
\end{lstlisting}

\subsubsection{Step 4: Database Setup}

\begin{lstlisting}[language=bash]
# Login to MySQL and create database
mysql -u root -p
CREATE DATABASE car_rental_db;
exit;

# Generate Prisma Client
npx prisma generate

# Run migrations to create tables
npx prisma migrate dev --name init
\end{lstlisting}

\subsubsection{Step 5: Run the Application}

\begin{lstlisting}[language=bash]
# Start development server
npm run dev

# Application runs at: http://localhost:3000
\end{lstlisting}

\section{Database Schema}

\subsection{Database Relationships}

The database consists of 5 main models:

\begin{itemize}
    \item \textbf{User}: Authentication and account management
    \item \textbf{Customer}: Customer information and profiles
    \item \textbf{Vehicle}: Fleet vehicle information
    \item \textbf{Rental}: Booking and rental records
    \item \textbf{Feedback}: Customer satisfaction ratings
\end{itemize}

\textbf{Relationships:}
\begin{itemize}
    \item User (1) $\rightarrow$ (Many) Customer
    \item Customer (1) $\rightarrow$ (Many) Rental
    \item Vehicle (1) $\rightarrow$ (Many) Rental
    \item Rental (1) $\rightarrow$ (1) Feedback
\end{itemize}

\section{Security}

\subsection{Security Best Practices Implemented}

\begin{enumerate}
    \item \textbf{Password Security}:
    \begin{itemize}
        \item Bcrypt hashing with salt rounds
        \item No plain text storage
        \item Strong password requirements
    \end{itemize}

    \item \textbf{JWT Security}:
    \begin{itemize}
        \item Secret key from environment
        \item Token expiration
        \item HTTPS only in production
    \end{itemize}

    \item \textbf{Input Validation}:
    \begin{itemize}
        \item Zod schema validation
        \item Type checking with TypeScript
        \item Sanitization of user inputs
    \end{itemize}

    \item \textbf{SQL Injection Prevention}:
    \begin{itemize}
        \item Prisma ORM with parameterized queries
        \item No raw SQL queries
    \end{itemize}
\end{enumerate}

\section{Troubleshooting}

\subsection{Common Issues and Solutions}

\subsubsection{Module not found errors}

\begin{lstlisting}[language=bash]
# Solution: Clear cache and reinstall
rm -rf node_modules
rm package-lock.json
npm install
\end{lstlisting}

\subsubsection{Database connection errors}

Check your \texttt{DATABASE\_URL} format:
\begin{lstlisting}
# Correct format:
DATABASE_URL="mysql://user:pass@host:port/database"
\end{lstlisting}

\subsubsection{Port 3000 already in use}

\begin{lstlisting}[language=bash]
# macOS/Linux
lsof -ti:3000 | xargs kill -9

# Windows
netstat -ano | findstr :3000
taskkill /PID <PID> /F
\end{lstlisting}
